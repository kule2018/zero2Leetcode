    35|**1、Softmax 定义为 $\operatorname{softmax}(x)_i=\dfrac{e^{x_i}}{\sum_j e^{x_j}}$。当部分 $x_i$ 很大时，正确的数值稳定化实现是？**
    36|
    37|A. 先对 $x$ 做 L2 归一化
    38|B. 将所有 $x_i$ 除以 $\max(x)$
    39|C. 只把中间变量改为 FP64
    40|D. 将所有 $x_i$ 减去 $\max(x)$ 后再计算 Softmax
    41|
    42|**答案**：D
    43|**难度**：入门
    44|**考点**：深度学习—Softmax/数值稳定性
    45|**解析**：分子、分母同乘 $e^{-\max(x)}$ 不改变结果，而所有指数自变量都变为非正数：
    46|
    47|$$
    48|\operatorname{softmax}(x)_i
    49|=\frac{e^{x_i-\max(x)}}{\sum_j e^{x_j-\max(x)}}.
    50|$$
    51|
    52|这样指数值落在 $(0,1]$ 内，可避免上溢。归一化或除以最大值都会改变分量间差值。

   297|**16、关于单位向量 $v$ 定义的 Householder 矩阵 $H=I-2vv^T$，正确的有？**
   298|
   299|A. $H$ 是正交矩阵
   300|B. $\det(H)=+1$
   301|C. Householder QR 通常比经典 Gram-Schmidt 数值稳定
   302|D. $H$ 是对称矩阵
   303|
   304|**答案**：A、C、D
   305|**难度**：中等
   306|**考点**：数学—Householder 变换/QR 分解
   307|**解析**：$H^T=H$，且
   308|
   309|$$
   310|H^TH=H^2=(I-2vv^T)^2=I.
   311|$$
   312|
   313|因此 H 对称且正交。它在 $v$ 方向上的特征值为 $-1$，其余方向为 $1$，故行列式为 $-1$。Householder 变换也具有较好的数值稳定性。

   379|## 第 1 题：基站空间重叠区域识别
   380|
   381|### 题目描述
   382|
   383|无线网络运维需要根据基站的密集程度识别信号重叠区域。给定 $N$ 个平面基站 $P_i(x_i,y_i)$、距离门限 $\varepsilon$ 和邻域数量门限 $MinPts$，定义：
   384|
   385|- **空间邻域**：若
   386|
   387|$$
   388|d(P_i,P_j)=|x_i-x_j|+|y_i-y_j|\le\varepsilon,
   389|$$
   390|
   391|则 $P_j$ 位于 $P_i$ 的邻域内。邻域包含基站自身。
   392|- **核心点（Core）**：邻域内基站总数不少于 $MinPts$。
   393|- **边界点（Border）**：自身不是核心点，但邻域内至少存在一个核心点。
   394|- **噪声点（Noise）**：既不是核心点，也不是边界点。
   395|
   396|请按输入顺序输出每个基站的类别：`0` 表示 Core，`1` 表示 Border，`2` 表示 Noise。
   397|
   398|### 输入格式
   399|
   400|第一行包含三个整数 $N,\varepsilon,MinPts$：
   401|
   402|- $1\le N\le2000$；
   403|- $0\le\varepsilon\le10000$；
   404|- $1\le MinPts\le N$。
   405|
   406|接下来 $N$ 行，每行包含两个整数 $x_i,y_i$，满足 $-10000\le x_i,y_i\le10000$。
   407|
   408|### 输出格式
   409|
   410|输出 $N$ 行，第 $i$ 行为第 $i$ 个基站的类别编号。
   411|
   412|### 样例 1
   413|
   414|**输入**
   415|
   416|```text
   417|5 1 2
   418|0 0
   419|1 0
   420|-1 0
   421|0 1
   422|0 -1
   423|```
   424|
   425|**输出**
   426|
   427|```text
   428|0
   429|0
   430|0
   431|0
   432|0
   433|```
   434|
   435|每个外围点的邻域都包含自身与原点，邻域规模至少为 $2$，因此五个点都是核心点。
   436|
   437|### 样例 2
   438|
   439|**输入**
   440|
   441|```text
   442|5 1 3
   443|0 0
   444|1 0
   445|0 1
   446|5 5
   447|9 9
   448|```
   449|
   450|**输出**
   451|
   452|```text
   453|0
   454|1
   455|1
   456|2
   457|2
   458|```
   459|
   460|原点的邻域规模为 $3$，是核心点；$(1,0)$ 与 $(0,1)$ 不是核心点，但与原点相邻，因此是边界点；其余两个点为噪声点。
   461|
   462|### 思路分析
   463|
   464|**第一步：统计邻域规模**
   465|
   466|初始化 `count[i] = 1`，因为每个基站与自身的距离为 $0$。只枚举 $i<j$ 的点对；若曼哈顿距离不超过 $\varepsilon$，同时增加两端的计数。
   467|
   468|**第二步：一次性确定所有核心点**
   469|
   470|$$
   471|P_i\in Core\iff count_i\ge MinPts.
   472|$$
   473|
   474|边界点的定义依赖最终核心点集合，因此不能边统计边判断，否则结果可能受遍历顺序影响。
   475|
   476|**第三步：标记非核心点**
   477|
   478|核心点直接输出 `0`。对每个非核心点扫描核心点集合，只要找到一个距离不超过 $\varepsilon$ 的核心点，就标为 `1`；否则标为 `2`。
   479|
   480|### 复杂度分析
   481|
   482|**时间复杂度**：$O(N^2)$。邻域计数需要枚举点对；边界点判断最坏也为平方级。
   483|**空间复杂度**：$O(N)$，用于保存坐标、邻域计数、核心点标记和答案。
   484|
   485|### Python 代码
   486|
   487|```python
   488|import sys
   489|
   490|
   491|def solve():
   492|    input = sys.stdin.readline
   493|    n, eps, min_pts = map(int, input().split())
   494|    points = [tuple(map(int, input().split())) for _ in range(n)]
   495|
   496|    # 邻域包含自身。
   497|    count = [1] * n
   498|
   499|    for i in range(n):
   500|        xi, yi = points[i]
   501|        for j in range(i + 1, n):
   502|            xj, yj = points[j]
   503|            if abs(xi - xj) + abs(yi - yj) <= eps:
   504|                count[i] += 1
   505|                count[j] += 1
   506|
   507|    # 必须先完整确定核心点集合。
   508|    is_core = [value >= min_pts for value in count]
   509|    core_indices = [i for i in range(n) if is_core[i]]
   510|
   511|    answer = [2] * n
   512|    for i in range(n):
   513|        if is_core[i]:
   514|            answer[i] = 0
   515|            continue
   516|
   517|        xi, yi = points[i]
   518|        for j in core_indices:
   519|            xj, yj = points[j]
   520|            if abs(xi - xj) + abs(yi - yj) <= eps:
   521|                answer[i] = 1
   522|                break
   523|
   524|    sys.stdout.write("\n".join(map(str, answer)))
   525|
   526|
   527|if __name__ == "__main__":
   528|    solve()
   529|```
   530|
   531|### 易错点
   532|
   533|1. **漏算自身**：邻域包含 $d=0$ 的自身，计数初值应为 `1`。
   534|2. **距离类型写错**：题目使用曼哈顿距离，不是欧氏距离，无需开平方。
   535|3. **边统计边标边界点**：应先确定全部核心点，再判断 Border。
   536|4. **重复坐标**：即使两个基站坐标相同，它们仍是两个不同输入点，彼此都应计入邻域。
   537|5. **边界为闭区间**：距离恰好等于 $\varepsilon$ 时也属于邻域。

   541|## 第 2 题：多 Agent 协作任务调度
   542|
   543|### 题目描述
   544|
   545|一个多 Agent 系统包含 $N$ 个 Agent。每调用一次第 $i$ 个 Agent，任务进度增加 $p_i$ 个百分点，并产生代价 $c_i$。每个 Agent 可以调用任意多次，但不能连续两次调用同一个 Agent。
   546|
   547|当累计进度达到或超过 $100$ 时任务完成，允许最终进度超过 $100$。请计算完成任务的最小总代价；若无法完成，输出 `-1`。
   548|
   549|### 输入格式
   550|
   551|第一行输入整数 $N$，满足 $1\le N\le10^5$。
   552|
   553|接下来 $N$ 行，每行包含两个整数 $p_i,c_i$：
   554|
   555|- $1\le p_i\le100$；
   556|- $1\le c_i\le10^4$。
   557|
   558|### 输出格式
   559|
   560|输出完成任务所需的最小总代价；若无解，输出 `-1`。
   561|
   562|### 样例 1
   563|
   564|**输入**
   565|
   566|```text
   567|1
   568|60 5
   569|```
   570|
   571|**输出**
   572|
   573|```text
   574|-1
   575|```
   576|
   577|只有一个 Agent，调用一次后进度为 $60$，第二次调用会违反相邻不同约束，因此无解。
   578|
   579|### 样例 2
   580|
   581|**输入**
   582|
   583|```text
   584|3
   585|30 1
   586|40 2
   587|100 50
   588|```
   589|
   590|**输出**
   591|
   592|```text
   593|4
   594|```
   595|
   596|依次调用 Agent 1、Agent 2、Agent 1，进度为 $30+40+30=100$，代价为 $1+2+1=4$。
   597|
   598|### 思路分析
   599|
   600|进度只需保留 $0$ 到 $99$：一旦达到 $100$，直接更新答案。由于 $p_i\ge1$，进度严格增加，可以按进度从小到大转移。
   601|
   602|朴素状态可定义为：
   603|
   604|$$
   605|dp[j][i]=\text{累计进度恰为 }j\text{，且最后调用 Agent }i\text{ 的最小代价}.
   606|$$
   607|
   608|若下一次调用 Agent $k$，需要求
   609|
   610|$$
   611|\min_{i\ne k}dp[j][i]+c_k.
   612|$$
   613|
   614|完整枚举 $i,k$ 的复杂度为 $O(100N^2)$，无法通过。注意：从一层状态中排除某个 Agent 后的最小值，只可能是该层的最小值或“属于另一个 Agent 的次小值”。
   615|
   616|对每个进度 $j$ 维护：
   617|
   618|- `best[j]`：这一层的最小代价；
   619|- `best_last[j]`：取得最小代价时最后调用的 Agent；
   620|- `second[j]`：最后一个 Agent 与 `best_last[j]` 不同的最小代价。
   621|
   622|转移到 Agent $k$ 时：
   623|
   624|$$
   625|base=
   626|\begin{cases}
   627|second[j],&k=best\_last[j],\\
   628|best[j],&k\ne best\_last[j].
   629|\end{cases}
   630|$$
   631|
   632|然后令 `new_cost = base + c[k]`。若 $j+p_k\ge100$，用它更新答案；否则把 `(new_cost, k)` 合并到目标进度层的最小值/次小值中。
   633|
   634|进度 $0$ 是虚拟起点，没有“上一个 Agent”。令 `best[0] = second[0] = 0` 且 `best_last[0] = -1`，即可让第一次调用任意 Agent。
   635|
   636|### 复杂度分析
   637|
   638|**时间复杂度**：$O(100N)$。最多处理 100 个进度层，每层扫描全部 Agent。
   639|**空间复杂度**：$O(N)$，用于保存所有 $p_i,c_i$；DP 数组长度固定为 100。
   640|
   641|### Python 代码
   642|
   643|```python
   644|import sys
   645|
   646|
   647|def solve():
   648|    input = sys.stdin.readline
   649|    n = int(input())
   650|    progress = [0] * n
   651|    cost = [0] * n
   652|
   653|    for i in range(n):
   654|        progress[i], cost[i] = map(int, input().split())
   655|
   656|    inf = 10**30
   657|
   658|    # best[j]：进度恰为 j 时的最小代价。
   659|    # second[j]：排除 best_last[j] 后，由另一个 Agent 结尾的最小代价。
   660|    best = [inf] * 100
   661|    second = [inf] * 100
   662|    best_last = [-1] * 100
   663|
   664|    # 虚拟起点：第一次调用不受“相邻不同”限制。
   665|    best[0] = 0
   666|    second[0] = 0
   667|
   668|    answer = inf
   669|
   670|    for current in range(100):
   671|        if best[current] == inf:
   672|            continue
   673|
   674|        for agent in range(n):
   675|            if agent == best_last[current]:
   676|                base = second[current]
   677|            else:
   678|                base = best[current]
   679|
   680|            if base == inf:
   681|                continue
   682|
   683|            new_cost = base + cost[agent]
   684|            next_progress = current + progress[agent]
   685|
   686|            if next_progress >= 100:
   687|                answer = min(answer, new_cost)
   688|                continue
   689|
   690|            # 将“代价 new_cost、末尾 agent”合并到目标层。
   691|            if new_cost < best[next_progress]:
   692|                if best_last[next_progress] == agent:
   693|                    # 同一 Agent 的状态变优，不影响异 Agent 次小值。
   694|                    best[next_progress] = new_cost
   695|                else:
   696|                    # 原最小值来自另一个 Agent，可成为新的次小值。
   697|                    second[next_progress] = best[next_progress]
   698|                    best[next_progress] = new_cost
   699|                    best_last[next_progress] = agent
   700|            elif (
   701|                best_last[next_progress] != agent
   702|                and new_cost < second[next_progress]
   703|            ):
   704|                second[next_progress] = new_cost
   705|
   706|    print(-1 if answer == inf else answer)
   707|
   708|
   709|if __name__ == "__main__":
   710|    solve()
   711|```
   712|
   713|### 易错点
   714|
   715|1. **把问题写成普通完全背包**：状态必须体现“上一个 Agent”，否则无法检查相邻不同约束。
   716|2. **次小值定义错误**：`second[j]` 必须来自与 `best_last[j]` 不同的 Agent，而不是简单的第二个数值。
   717|3. **同一 Agent 刷新最小值时误改次小值**：若最小值持有者不变，只更新 `best`，不能覆盖 `second`。
   718|4. **达到 100 后仍继续转移**：题目在进度达到或超过 $100$ 时即完成，直接更新答案即可。
   719|5. **单 Agent 特例**：若仅有一个 Agent 且 $p_1<100$，最多合法调用一次，答案为 `-1`；上述 DP 会自然得到该结果。
   720|6. **初始化不当**：进度 $0$ 尚无上一个 Agent，必须允许任意 Agent 作为第一次调用。
