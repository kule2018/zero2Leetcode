# LeetCode-002：两数相加，链表加法的关键不是"怎么加"，而是"怎么处理进位和对齐"

> 配套刷题网站 [Zero2Leetcode](https://onefly.top/zero2Leetcode/) —— 内置本地 OJ + AI 教练，零门槛开刷 Hot 100。

## 一、题目概述

给定两个非空链表，分别表示两个非负整数。每个节点存储一位数字，且数字按**逆序**存储（即个位在链表头部）。

将两个数相加，并以相同的链表形式返回结果。

例如：

### 示例 1

```
l1: 2 -> 4 -> 3       （表示 342）
l2: 5 -> 6 -> 4       （表示 465）
```

输出：

```
7 -> 0 -> 8           （表示 807）
```

因为 342 + 465 = 807。

---

### 示例 2

```
l1: 0
l2: 0
```

输出：

```
0
```

---

### 示例 3

```
l1: 9 -> 9 -> 9 -> 9 -> 9 -> 9 -> 9   （表示 9999999）
l2: 9 -> 9 -> 9 -> 9                    （表示 9999）
```

输出：

```
8 -> 9 -> 9 -> 9 -> 0 -> 0 -> 0 -> 1   （表示 10009998）
```

---

## 二、核心思路

这道题的本质就是**模拟竖式加法**。

回忆一下小学怎么做加法：从个位开始，逐位相加，满十进一。这里链表已经帮你倒好序了——头节点就是个位，直接从头开始加就行。

整个过程只需要关注三件事：

1. **逐位相加**：每一轮取 `l1` 和 `l2` 当前节点的值，加上上一轮的进位
2. **计算进位**：当前位的值如果 >= 10，就要产生进位 1，当前位只保留个位数字
3. **处理长度不同**：两个链表不一定一样长，短的那条走完后，对应位的值当作 0 继续加

还有一个容易忽略的情况：

> 最后一位加完之后，如果还有进位（比如 99 + 1 = 100），需要额外创建一个新节点来存这个进位。

为了简化链表头节点的处理，我们用一个 **dummy 节点**（哨兵节点）作为结果链表的起点，最后返回 `dummy.next`。

---

## 三、代码实现

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        current = dummy
        carry = 0

        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0

            total = val1 + val2 + carry
            carry = total // 10
            current.next = ListNode(total % 10)
            current = current.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy.next
```

---

## 四、逐行拆解

### 1. 创建哨兵节点和进位变量

```python
dummy = ListNode(0)
current = dummy
carry = 0
```

`dummy` 是一个虚拟头节点，它本身不存有效数据，作用是让我们不用单独处理"第一个节点怎么创建"这个特殊情况。`current` 指向当前结果链表的尾部，用来往后接新节点。`carry` 记录进位，初始为 0。

---

### 2. 循环条件：只要还有数字没加完，或者还有进位

```python
while l1 or l2 or carry:
```

这个条件覆盖了三种需要继续的情况：

- `l1` 还有节点没遍历完
- `l2` 还有节点没遍历完
- 上一轮产生了进位（比如最高位 9 + 9 = 18，还要再加一个节点）

把 `carry` 也放进循环条件里，就不需要在循环结束后单独判断"还有没有进位要处理"了。

---

### 3. 取当前位的值，短链表用 0 补齐

```python
val1 = l1.val if l1 else 0
val2 = l2.val if l2 else 0
```

如果某条链表已经走完（节点为 `None`），对应的值就是 0。这就像竖式加法里短的数前面补零一样。

---

### 4. 计算当前位的结果和进位

```python
total = val1 + val2 + carry
carry = total // 10
current.next = ListNode(total % 10)
current = current.next
```

- `total` 是当前位两个数字加上进位的总和
- `carry = total // 10`：整除 10 得到新的进位（要么是 0，要么是 1）
- `total % 10`：取个位数字，作为结果链表当前节点的值
- 把新节点接到 `current` 后面，然后 `current` 往前移一步

---

### 5. 推进两个输入链表的指针

```python
if l1:
    l1 = l1.next
if l2:
    l2 = l2.next
```

只有在链表还没走完的时候才推进指针，避免对 `None` 调用 `.next` 报错。

---

### 6. 返回结果

```python
return dummy.next
```

`dummy` 是虚拟头节点，真正的结果从 `dummy.next` 开始。

---

## 五、手动模拟

以 `l1 = [2, 4, 3]`，`l2 = [5, 6, 4]` 为例（即 342 + 465 = 807）：

| 步骤 | l1 节点 | l2 节点 | carry（进入时） | total | 新节点值 | carry（产出） |
|------|---------|---------|-----------------|-------|----------|---------------|
| 第 1 轮 | 2 | 5 | 0 | 7 | 7 | 0 |
| 第 2 轮 | 4 | 6 | 0 | 10 | 0 | 1 |
| 第 3 轮 | 3 | 4 | 1 | 8 | 8 | 0 |

循环结束后，`l1`、`l2` 都为 `None`，`carry` 为 0，三个条件都不满足，退出循环。

结果链表：`7 -> 0 -> 8`，即 807。

---

再看一个需要最终进位的例子：`l1 = [9, 9]`，`l2 = [1]`（即 99 + 1 = 100）：

| 步骤 | l1 节点 | l2 节点 | carry（进入时） | total | 新节点值 | carry（产出） |
|------|---------|---------|-----------------|-------|----------|---------------|
| 第 1 轮 | 9 | 1 | 0 | 10 | 0 | 1 |
| 第 2 轮 | 9 | None(补0) | 1 | 10 | 0 | 1 |
| 第 3 轮 | None | None | 1 | 1 | 1 | 0 |

第 3 轮时两条链表都走完了，但 `carry = 1`，所以循环继续执行，创建了值为 1 的节点。

结果链表：`0 -> 0 -> 1`，即 100。

---

## 六、复杂度分析

**时间复杂度：O(max(m, n))**

- `m` 和 `n` 分别是两条链表的长度
- 循环次数等于较长链表的长度（如果最后有进位，再多一轮）
- 每一轮只做常数次操作

**空间复杂度：O(max(m, n))**

- 结果链表的长度最多为 `max(m, n) + 1`（多出的 1 是最终进位）
- 除了结果链表之外，只用了几个额外变量

---

## 七、总结

这道题的标准解法是：

```python
class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        dummy = ListNode(0)
        current = dummy
        carry = 0

        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0

            total = val1 + val2 + carry
            carry = total // 10
            current.next = ListNode(total % 10)
            current = current.next

            if l1:
                l1 = l1.next
            if l2:
                l2 = l2.next

        return dummy.next
```

有三个细节最值得记住：

- **循环条件写 `while l1 or l2 or carry`**，把进位也纳入循环条件，就不用在循环外单独处理最后的进位
- **用 dummy 节点简化链表构建**，不需要对第一个节点做特殊判断，最后返回 `dummy.next`
- **短链表用 0 补齐**，`l1.val if l1 else 0` 这个写法让两条链表长度不同时也能统一处理

这题是链表模拟题的经典入门。把"逐位加、算进位、用 dummy 节点"这套模板吃透，后面遇到链表相关的加法、乘法、合并等题目都会用到类似的思路。
