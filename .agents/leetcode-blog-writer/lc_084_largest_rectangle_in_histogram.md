## 题目概述

给定柱状图每根柱子的高度 `heights`，求能形成的最大矩形面积。矩形必须由连续柱子组成，高度取这些柱子中的最小高度。

## 核心思路：以每根柱子为“最矮高度”，找它能向左右扩到哪里

如果固定某根柱子高度为 `h` 作为矩形的最小高度，那么它能扩展的左右边界，分别是：

- 左边第一个严格小于 `h` 的位置 `L`
- 右边第一个严格小于 `h` 的位置 `R`

那么以它为最矮柱的最大宽度就是 `(R - L - 1)`，面积为 `h * (R - L - 1)`。

问题变成：对每个位置，快速找到左右第一个更矮的位置。单调递增栈就是为这个服务的。

## 单调栈做法（推荐）

维护一个“高度递增”的栈，栈里存下标。遍历到新柱子 `i` 时：

- 如果 `heights[i]` 小于栈顶高度，说明栈顶那根柱子的“右边界”找到了，就是 `i`
- 连续弹出直到栈重新递增
- 被弹出的柱子 `mid`，其左边界就是弹出后新的栈顶 `left_less`

为了让所有柱子都能在遍历结束时被结算，常见做法是首尾加哨兵 `0`。

## 代码实现（Python，可直接提交）

```python
from typing import List


class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        # 哨兵：避免处理空栈边界，保证最后能把栈清空结算
        a = [0] + heights + [0]
        st = []  # 单调递增栈，存下标
        ans = 0

        for i, h in enumerate(a):
            while st and a[st[-1]] > h:
                mid = st.pop()
                left_less = st[-1]  # 弹出 mid 后的栈顶一定存在（因为左侧有 0 哨兵）
                width = i - left_less - 1
                ans = max(ans, a[mid] * width)
            st.append(i)

        return ans
```

## 逐行拆解：弹栈时为什么能确定面积？

当 `mid` 被弹出时，有两个事实成立：

- 右边第一个更矮的柱子就是当前 `i`（因为 `a[i] < a[mid]`，且中间都不比 `a[mid]` 更矮，否则会更早弹出）
- 左边第一个更矮的柱子就是弹出后栈顶 `left_less`（栈保持递增，`a[left_less] < a[mid]`）

因此 `mid` 的“最大扩展宽度”在这一刻被确定了，面积可以安全结算一次。

## 手动模拟（heights = [2,1,5,6,2,3]）

加哨兵后：`[0,2,1,5,6,2,3,0]`

关键弹栈点：

- 扫到高度 `1` 时，`2` 被弹出，面积 `2 * 1`
- 扫到高度 `2` 时，`6`、`5` 依次被弹出，得到面积 `6*1`、`5*2`
- 扫到末尾 `0` 时，栈内剩余柱子全被清算

最终最大面积为 `10`（由高度 5，宽度 2 的矩形得到）。

## 复杂度分析

- 时间复杂度：`O(n)`，每个下标最多入栈一次、出栈一次
- 空间复杂度：`O(n)`，栈存下标

## 总结

这题的关键不是“栈很神”，而是边界定义非常明确：

- 以某根柱子为最矮，最大矩形只取决于它左右第一个更矮的柱子
- 单调栈把“找边界”这件事做成线性时间
