# LeetCode-394：字符串解码，遇到嵌套括号别慌，用栈把"之前的状态"存起来就行

## 一、题目概述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则是 `k[encoded_string]`，表示其中的 `encoded_string` 重复 `k` 次。你可以认为输入字符串总是合法的，不会有多余的空格，方括号总是成对出现。

### 示例 1

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

`3[a]` 表示 `a` 重复 3 次，得到 `"aaa"`。`2[bc]` 表示 `bc` 重复 2 次，得到 `"bcbc"`。拼起来就是 `"aaabcbc"`。

---

### 示例 2

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

先看最里层：`2[c]` 表示 `c` 重复 2 次，得到 `"cc"`。代入外层变成 `3[acc]`，即 `"acc"` 重复 3 次，得到 `"accaccacc"`。

---

### 示例 3

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

---

### 示例 4

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

括号外面的普通字母直接保留。

---

## 二、核心思路

这道题的难点在于**括号可以嵌套**，比如 `3[a2[c]]`。你必须先解码里层的 `2[c]` 得到 `"cc"`，再和外层的 `a` 拼成 `"acc"`，最后重复 3 次。

怎么处理这种"先遇到的要后处理"的嵌套结构？答案就是**栈**。

栈的本质是"后进先出"，天然适合处理嵌套结构。思路是这样的：

> 遍历字符串的每个字符，分四种情况处理：
>
> 1. **遇到数字**：可能是多位数，要把完整的数字拼出来
> 2. **遇到 `[`**：说明一个新的嵌套层开始了。把当前已经积累的字符串和数字**压入栈中保存**，然后重置它们，开始记录新一层的内容
> 3. **遇到 `]`**：说明当前这一层结束了。从栈中**弹出**上一层的字符串和重复次数，把当前层的字符串重复对应次数后，拼接到上一层的字符串后面
> 4. **遇到普通字母**：直接追加到当前正在构建的字符串上

关键洞察是：**每次遇到 `[`，就是进入了一个新的"上下文"。栈的作用就是保存旧的上下文，等 `]` 出现时恢复它。**

## 三、代码实现

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []
        cur_str = ""
        cur_num = 0

        for ch in s:
            if ch.isdigit():
                cur_num = cur_num * 10 + int(ch)
            elif ch == '[':
                stack.append((cur_str, cur_num))
                cur_str = ""
                cur_num = 0
            elif ch == ']':
                prev_str, num = stack.pop()
                cur_str = prev_str + cur_str * num
            else:
                cur_str += ch

        return cur_str
```

## 四、逐行拆解代码

### 1. 初始化栈和两个临时变量

```python
stack = []
cur_str = ""
cur_num = 0
```

- `stack`：用来保存外层的上下文（外层已积累的字符串 + 当前层要重复的次数）
- `cur_str`：当前层正在构建的字符串
- `cur_num`：当前正在读取的数字（可能是多位数）

---

### 2. 遍历每一个字符

```python
for ch in s:
```

逐个字符处理，根据字符类型分四种情况。

---

### 3. 遇到数字：拼出完整的多位数

```python
if ch.isdigit():
    cur_num = cur_num * 10 + int(ch)
```

比如遇到 `"12[a]"` 中的 `1` 和 `2`，第一次 `cur_num = 0 * 10 + 1 = 1`，第二次 `cur_num = 1 * 10 + 2 = 12`。这个 `* 10` 的技巧可以正确处理任意位数的数字。

---

### 4. 遇到 `[`：把当前状态压栈，开始新的一层

```python
elif ch == '[':
    stack.append((cur_str, cur_num))
    cur_str = ""
    cur_num = 0
```

遇到 `[` 意味着要进入一个新的嵌套层。在进入之前，先把"当前层已经积累的字符串"和"接下来这一层要重复的次数"打包存到栈里。

然后把 `cur_str` 和 `cur_num` 重置，从零开始记录新一层的内容。

**这一步是整个算法的核心。** 你可以把它理解为"存档"——进入新副本之前先存个档，等通关了（遇到 `]`）再读档回来。

---

### 5. 遇到 `]`：弹出上一层的状态，拼接结果

```python
elif ch == ']':
    prev_str, num = stack.pop()
    cur_str = prev_str + cur_str * num
```

遇到 `]` 说明当前层结束了。从栈里弹出上一层的字符串 `prev_str` 和当前层要重复的次数 `num`。

把当前层的字符串 `cur_str` 重复 `num` 次，拼接到上一层字符串的后面，得到新的 `cur_str`。

**这一步就是"读档"——回到上一层的状态，并把当前层的成果合并进去。**

---

### 6. 遇到普通字母：直接追加

```python
else:
    cur_str += ch
```

不是数字、不是括号，那就是普通字母，直接加到当前正在构建的字符串上。

---

### 7. 返回最终结果

```python
return cur_str
```

遍历结束后，`cur_str` 就是完全解码后的字符串。

## 五、手动模拟

用 `"3[a2[c]]"` 完整走一遍：

| 步骤 | 字符 | 操作 | cur_num | cur_str | 栈 |
|------|------|------|---------|---------|-----|
| 1 | `3` | 读数字 | 3 | `""` | `[]` |
| 2 | `[` | 压栈，重置 | 0 | `""` | `[("", 3)]` |
| 3 | `a` | 追加字母 | 0 | `"a"` | `[("", 3)]` |
| 4 | `2` | 读数字 | 2 | `"a"` | `[("", 3)]` |
| 5 | `[` | 压栈，重置 | 0 | `""` | `[("", 3), ("a", 2)]` |
| 6 | `c` | 追加字母 | 0 | `"c"` | `[("", 3), ("a", 2)]` |
| 7 | `]` | 弹出 `("a", 2)` | 0 | `"a" + "c" * 2 = "acc"` | `[("", 3)]` |
| 8 | `]` | 弹出 `("", 3)` | 0 | `"" + "acc" * 3 = "accaccacc"` | `[]` |

最终返回 `"accaccacc"`，和预期一致。

来看关键步骤的细节：

- **步骤 2**：遇到第一个 `[`，把当前空字符串和数字 3 压栈。意思是"等里面的内容解码完了，要重复 3 次，拼在空字符串后面"
- **步骤 5**：遇到第二个 `[`，把当前字符串 `"a"` 和数字 2 压栈。意思是"等里面的内容解码完了，要重复 2 次，拼在 `"a"` 后面"
- **步骤 7**：遇到第一个 `]`，弹出 `("a", 2)`，当前的 `"c"` 重复 2 次得到 `"cc"`，拼在 `"a"` 后面得到 `"acc"`
- **步骤 8**：遇到第二个 `]`，弹出 `("", 3)`，当前的 `"acc"` 重复 3 次得到 `"accaccacc"`，拼在空字符串后面还是 `"accaccacc"`

## 六、复杂度分析

**时间复杂度：O(n)**

- `n` 是解码后字符串的总长度
- 每个字符在最终结果中最多被构建一次
- 遍历原字符串是 O(|s|)，但字符串拼接的总工作量取决于输出长度

**空间复杂度：O(n)**

- 栈的深度取决于嵌套层数
- `cur_str` 在过程中可能持有部分解码结果
- 最坏情况下空间与输出长度成正比

---

## 七、总结

这道题的核心洞察就一句话：

> 嵌套结构用栈来处理。遇到 `[` 就把当前状态存进栈里（存档），遇到 `]` 就从栈里恢复上一层的状态（读档），并把当前层的结果合并回去。

整个解法的关键在于想清楚**栈里存什么**。这道题里，栈中每一项存的是一个元组 `(prev_str, num)`：

- `prev_str`：进入当前 `[...]` 之前已经积累的字符串
- `num`：当前 `[...]` 里的内容要重复多少次

另外一个容易忽略的细节是**多位数的处理**。题目中的数字可能不只一位，比如 `"12[a]"`，所以每次遇到数字字符时要用 `cur_num = cur_num * 10 + int(ch)` 来逐位累加。

这道题是栈处理嵌套结构的经典入门题。同样的"存档-读档"思路在很多地方都会用到，比如计算器求值（嵌套括号里的加减乘除）、HTML/JSON 的嵌套解析等。把这个模式吃透，遇到类似的嵌套处理问题就不会慌了。
