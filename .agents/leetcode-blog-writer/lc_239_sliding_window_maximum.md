## 题目概述

给定数组 `nums` 和窗口大小 `k`，窗口从左到右滑动，每次输出窗口内的最大值。

要求通常是线性时间，否则 `O(nk)` 会超时。

例如：

- 输入：`nums = [1,3,-1,-3,5,3,6,7]`，`k = 3`
- 输出：`[3,3,5,5,6,7]`


## 核心思路：用单调递减队列存“下标”

队列里存的是下标而不是值，原因是需要判断元素是否“过期”离开窗口。

维护规则：

- 队头永远是当前窗口最大值的下标
- 新元素入队前，把队尾所有比它小（或等于）的元素弹出，因为它们不可能再成为最大值
- 每步滑动时，如果队头下标已经不在窗口范围内，就从队头弹出

## 代码实现（Python，可直接提交）

```python
from collections import deque
from typing import List


class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        if not nums or k <= 0:
            return []

        q = deque()  # 存下标，且 nums[q[0]] >= nums[q[1]] >= ...
        ans = []

        for i, x in enumerate(nums):
            # 1) 清理队头：不在窗口 [i-k+1, i] 内的下标过期
            while q and q[0] <= i - k:
                q.popleft()

            # 2) 维护单调性：队尾比当前小的都没机会了
            while q and nums[q[-1]] <= x:
                q.pop()

            q.append(i)

            # 3) 形成第一个窗口后开始记录答案
            if i >= k - 1:
                ans.append(nums[q[0]])

        return ans
```

## 逐行拆解：两种弹出分别在解决什么问题？

- `popleft()`：解决“过期”。下标小于 `i-k+1` 就说明元素已经滑出窗口
- `pop()`：解决“被支配”。如果 `nums[q[-1]] <= nums[i]`，那么后者更大且更晚过期，队尾元素永远不可能再成为最大值

## 手动模拟（以 nums=[1,3,-1,-3,5,3,6,7], k=3）

队列存下标，且对应值单调递减：

- i=0, 1 入队：q=[0] (值 [1])
- i=1, 3 入队：弹出 1，q=[1] (值 [3])
- i=2, -1 入队：q=[1,2] (值 [3,-1])，第一个窗口最大值=3
- i=3, -3 入队：q=[1,2,3]，最大仍是 3
- i=4, 5 入队：先清理过期（下标 1 过期），再弹出所有 <=5，q=[4]，最大=5

一路滑动就能得到答案 `[3,3,5,5,6,7]`。

## 复杂度分析

- 时间复杂度：`O(n)`，每个下标最多入队一次、出队一次
- 空间复杂度：`O(k)`，队列长度不超过窗口大小

## 总结

单调队列不是“魔法结构”，它只做两件事：

- 把窗口外的候选从队头清理掉
- 把被新元素支配的候选从队尾清理掉

剩下的就是：队头始终对应当前窗口最大值。
