# 哈希表

**核心知识点：**
- O(1) 查找
- 计数与去重
- 两数之和模式

**Python 实现：**
```python
# Counter 快速计数
from collections import Counter
count = Counter(arr)

# defaultdict 默认值
from collections import defaultdict
graph = defaultdict(list)
```
